# LRX

Experimento de apresentação visual para serviços automotivos. O site associado ao projeto está em desenvolvimento separado do código deste repositório.

## Registro atual

Este repositório contém a documentação do conceito, mas ainda não a aplicação. Por isso, o GitHub não exibe linguagens de programação.

## Direção

A proposta é desenvolver uma apresentação de serviços com identidade própria, informações comerciais verificadas e navegação simples. O conteúdo final depende da confirmação do negócio.
