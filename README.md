# LRX

Experimento de apresentação visual para serviços automotivos.

## Direção do projeto

A proposta é criar uma página que apresente os serviços, as informações comerciais e os canais de contato de forma simples. Os detalhes finais dependem de confirmação do negócio.

## Registro atual

Este repositório contém a documentação do conceito, mas ainda não a aplicação. Por isso, o GitHub não exibe linguagens de programação.

## Próxima etapa

Confirmar o escopo e o material visual autorizado. Quando a implementação começar, registrar aqui como instalar e executar o site e quais partes estão concluídas.
